第一次使用，在哪里查看令牌？

服务首次启动后，令牌保存在数据目录的 admin-token 文件中。默认读取命令：

Windows PowerShell

Get-Content .data/admin-token

macOS / Linux

cat .data/admin-token

令牌仅保存在当前浏览器会话。
