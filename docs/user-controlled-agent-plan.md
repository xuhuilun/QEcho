# QEcho 实施计划

1. 在 `feature/user-controlled-agent` 完成设计与接口约定，审阅范围及默认行为。
2. 实现配置、联系人、SQLite 存储、人格提示词和会话引擎；验证权限与发送状态机。
3. 实现模型和 OneBot HTTP 适配器；验证真实协议结构、错误处理与发送结果未知。
4. 实现中文控制台：联系人授权、人格编辑、演练、会话、全局暂停和连接设置。
5. 组装 API、管理认证、事件认证和后台任务；运行自动化与浏览器集成验证。
6. 补齐 README、部署说明、接口说明与实际验证记录，提交功能分支；验证远程没有新增提交后合并主分支并正常推送。

## 验收边界

提供可本地启动、可使用演练模型体验、可配置真实模型与 OneBot 桥接的应用。没有模型密钥和 QQ 登录条件时，不宣称真实聊天已经验证。不在开发过程中向真实联系人发送消息。
