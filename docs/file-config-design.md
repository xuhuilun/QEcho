# 集中配置与一键启动设计

## 使用方式

仓库提供 `qecho.example.toml`，真实配置为已被 Git 忽略的 `qecho.toml`。用户填写模型、QQ 服务与令牌、好友 QQ 号、提示词和自动启动选项后，双击 Windows 的 `start.bat`、macOS 的 `start.command`，或在 Linux 执行 `./start.sh`。脚本安装 Python 3.12、按锁定文件安装依赖并启动。

首次没有配置时，脚本仅复制样例并提示编辑后退出，不以占位参数启动。QQ 登录仍由 NapCat 完成，启动器不安装桥接或代替用户确认扫码。文件中的访问令牌需与 NapCat 对应配置一致。

## 配置结构

使用标准库 `tomllib`，无需新依赖。字段分为：

- `[server]`：`host`、`port`、`data_dir`、`admin_token`。
- `[model]`：`mode`、`base_url`、`name`、`api_key`、`temperature`、`context_messages`、`max_reply_chars`。
- `[qq]`：`api_url`、`api_token`、`login_url`、`event_token`。
- `[agent]`：`friends`（QQ 号字符串列表）、`prompt`、`auto_start`、`reply_delay_seconds`。

相对数据目录按配置文件所在目录解析。文件在启动时完整读取和校验，不做热重载。文件值优先于旧 `QECHO_*` 环境值；未使用文件时保持既有环境配置与网页模式。留空管理/事件令牌使用数据目录中生成的令牌；文件中留空模型/桥接密钥会清除数据库旧值，不能隐式复用。

## 入口与错误

`uv run qecho` 自动发现当前目录的 `qecho.toml`。`--config PATH` 显式指定文件；`QECHO_CONFIG` 可指定配置路径。`--check-config` 只检查配置，不启动服务，不打印密钥。显式路径缺失、语法或字段错误应清晰退出，不能退回旧配置。错误信息只包含字段名称和错误类型，不包含原值或完整文件。

## 文件模式

配置文件提供模型、连接、好友范围和提示词初始值。SQLite 保留消息、身份绑定、发送状态和网页保存的提示词。获取数据目录实例锁后，在单个事务内导入文件配置、暂停旧自动回复、递增版本并取消未发送任务。[网页提示词即时保存](live-prompt-editor.md)

配置 `auto_start=true` 后，以后台协调任务等待桥接登录，再按文件计划调用现有同步与启动校验。只读查询的连接故障、超时、HTTP 408/429/5xx 和尚无登录账号允许等待重试；HTTP 401/403/404、错误地址和格式不兼容等问题终止并提示配置错误。桥接的 `retryable` 与发送结果 `uncertain` 独立，发送请求不自动重试。启动成功后不重复重启。非暂时的账号/好友/配置错误停止并报告。网页提供状态、最近结果、提示词保存和停止。联系人范围与连接设置由文件管理。QQ 只读同步与后台启动使用同一协调锁。

停止先同步提交暂停屏障，再永久取消本轮后台启动。停止不等待模型、桥接或协调锁，等待登录/开始中的任务不能在停止后自动恢复。服务退出先取消并等待后台任务，再关闭引擎、HTTP 客户端和数据库。恢复使用关闭并重新启动进程的明确操作。

联系人版本快照跨准备、启动和重试间隔保留，仅允许初次账号绑定产生的已知版本增量。网络等待或重试间隔出现较新的人工接管时，终止自动启动，不能刷新快照后覆盖。启动成功后不再维护该启动快照，普通只读同步不会撤销人工接管或重新启动。永久错误以固定脱敏文案在状态页和终端各报告，等待重试不反复刷日志。

## 一键脚本

三个脚本固定进入自身目录，支持路径空格，不自动安装 uv 或 NapCat。缺 uv 时提示安装。Windows 使用 `call uv` 并在错误时保留退出码、停留提示；macOS 的 `.command` 复用 `.sh` 并在交互终端结束后保留结果。Unix 脚本可执行且使用 LF，批处理通过属性文件保持 CRLF。

## 验证

验证完整/错误/未知字段/BOM/TOML相对路径与密钥脱敏、旧环境兼容、文件导入清旧值、后台等待登录与正确启动、停止与网络等待竞态、网页写保护、启动器首次复制/路径空格/命令顺序/失败中止。使用模拟 uv 和桥接，不实际安装或登录 QQ。Windows/Linux CI 运行脚本与后端测试，本机验证可运行流程。
