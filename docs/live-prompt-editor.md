# 网页提示词即时保存

文件模式的提示词卡提供范围选择，管理员可以保存全局、已有分组或名单内好友的提示词。清空好友个人提示词后恢复继承。分组名称、成员和代聊范围仍通过 TOML 配置。编辑使用独立版本，保存时发现另一个页面已经写入新版本会提示冲突并保留草稿。

SQLite 保存三层生效提示词和版本。首次加载时从文件初始化。同一个配置文件路径、好友分组和提示词定义再次启动时保留网页保存值。手工修改文件的名单、分组或提示词后重启，会重新以文件为准。模型、连接和启动开关等改动不影响提示词保存值。网页保存不改写 TOML。

保存事务更新提示词并使尚未开始发送的旧版本回复失效。运行中的代聊保持启用，下一次来信使用新文本。已开始的发送请求可能已经送达。等待登录或核验名单期间可以保存，首次启用读取最新全局文本。文件模式原有账号、停止和人工接管保护继续生效。

实施顺序是先接入提示词持久化、启动和引擎版本检查，再接入管理员保存接口和编辑器，最后验证保存后的消息、进行中的模型请求、启动并发、版本冲突与进程重开。
