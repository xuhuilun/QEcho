## 浏览器实测

使用独立的临时数据目录、虚构联系人和仅监听本机的模拟模型/桥接接口。没有操作实际 QQ 账号。

- 管理令牌登录，初始全局暂停与未授权联系人状态正确。
- 创建联系人，选择“和喜欢的人聊天”预设，编辑关系和事实，保存成功。
- 提示词预览包含已保存的人格、语气、关系、事实和补充指令。
- 默认演练模型可运行；切换到本地 HTTP 模拟模型后，收到接口返回的完整回复；演练无发送按钮。
- 注入符合 OneBot 结构的好友事件，后台产生待确认草稿；浏览器编辑并确认后，模拟桥接收到精确修改后的文本。
- 切换指定联系人至自动模式，后续事件自动回复到模拟桥接。
- 人工接管与全局暂停后，再次注入事件被忽略；模拟桥接发送计数保持 2 次。
- 390×844 窄屏下检查会话和人格面板展开/关闭，桌面三栏布局正常。
- 浏览器未观察到脚本错误或警告。

最终新增账号校验后，使用本机模拟接口再次走通账号查询、模型生成、一次自动发送及暂停后拒绝后续事件，发送计数保持 1；与前述浏览器演练使用独立重启后的模拟计数。该检查仍不涉及真实 QQ 或真实模型。

## 没有验证的项目

- 真实模型服务的鉴权、费用、可用性、人格遵从率和回复质量。
- NapCat 实际安装登录、真实 QQ 收发、不同 QQ 设备的自身消息回报及版本兼容性。
- Docker 镜像构建和容器运行。
- 多账号、多人、多进程、分布式运行、图片/语音、群聊与大规模性能。

## 当前产品限制

人格与语气采用可编辑提示词和最近消息窗口，不包含训练、向量记忆或长期自动摘要。自然语言配置的实际效果取决于选用的模型；授权对象与发送暂停由程序检查。

程序不能撤回已经开始的 QQ 发送。超时后不自动重试；重启取消未完成任务且不补发。数据存储在本机 SQLite，未做数据库加密。用户需自行配置模型与 QQ 桥接后，再执行真实环境验收。
